# 🐍 HONOR Snake Escape | لعبة تحرير الثعابين

لعبة ألغاز وذكاء استراتيجية تعتمد على تحرير الثعابين المتشابكة بالترتيب الصحيح قبل نفاد المسارات، مع نظام تدرج تصاعدي يمتد عبر **100 مرحلة**، ومدعومة بنظام **محفظة HONOR الداخلية** للمنظومة الترفيهية.

🌐 **رابط التجربة المباشرة (Web Version):**  
https://puresoft-mainal.github.io/honor-snake-escape/
---

## 🎮 مميزات اللعبة ونظام التحدي
* **تصميم بصري واقعي:** ثعابين ذات أجسام انسيابية ورؤوس بارزة بألوان مجموعات مميزة، مع دعم **التكبير والتصغير (Zoom & Pan)** باللمس للتحكم الدقيق في المراحل المزدحمة.
* **تدرج تصاعدي ضخم (100 مرحلة):** تبدأ المرحلة الأولى بـ **15 ثعباناً**، ويزداد العدد بمقدار **10 ثعابين** في كل مرحلة حتى يصل إلى **1000 ثعبان** في المرحلة الأخيرة.
* **نظام الاحتراق الفوري:** أي محاولة لتحرير ثعبان في مسار مسدود تؤدي إلى اصطدامه واحتراقه فوراً وعدم احتسابه.
* **نظام العدّ الصارم (بعد المرحلة 25):** بدءاً من المرحلة 26، يتم تسجيل الثعابين المحررة بطريقة صحيحة فقط في العداد التراكمي للاعب.

## 🔒 الخصوصية وحماية بيانات اللاعب (Privacy & Device Auth)
تلتزم اللعبة بأعلى معايير الخصوصية وحماية بيانات المستخدمين:
1. **عدم جمع البيانات الشخصية:** لا تطلب اللعبة إنشاء حساب بالبريد الإلكتروني أو رقم الهاتف، ولا تقوم بجمع أو إرسال أي بيانات شخصية إلى خوادم خارجية.
2. **الدخول عبر بصمة الجهاز (`DeviceAuth`):** يتم توليد معرّف فريد ومشفّر محلياً على جهاز اللاعب لربط عنوان محفظته وتقدمه في المراحل بجهازه دون الحاجة لكلمات مرور.
3. **التخزين والنسخ الاحتياطي المحلي:** تُحفظ جميع بيانات التقدم والرصيد محلياً على الجهاز (`Local Storage`)، مع توفير ميزة تصدير واستعادة ملف النسخ الاحتياطي المشفّر على ذاكرة الجهاز لحماية رصيد اللاعب ومراحله عند إعادة تثبيت التطبيق.

## 🏗️ الهيكلة المعيارية للمشروع (Modular Architecture)
تم بناء المشروع وفق نظام فصل المهام بحيث يكون كل نظام في ملف مستقل لسهولة الصيانة والتطوير:

```text
honor-snake-escape/
├── index.html                 # الهيكل الرئيسي وواجهات اللعب والمحفظة
├── css/
│   └── style.css              # التصميم المتجاوب وألوان النيون
└── js/
    ├── device_auth.js         # نظام البصمة التعريفية للجهاز والنسخ الاحتياطي
    ├── database.js            # قاعدة البيانات وحفظ التقدم والعداد التراكمي
    ├── wallet.js              # محفظة HONOR والتسعير التصاعدي (45%) ونظام التحويل
    ├── camera.js              # نظام الكاميرا والتكبير والسحب (Zoom & Pan)
    ├── generator.js           # مولد المراحل الذكي (من 15 إلى 1000 ثعبان)
    ├── effects.js             # المؤثرات البصرية وجزيئات الاحتراق
    ├── audio.js               # المؤثرات الصوتية المولدة برمجياً
    ├── renderer.js            # محرك الرسم الانسيابي للثعابين والحواجز
    ├── physics.js             # محرك الفيزياء واكتشاف التصادم
    └── main.js                # وحدة التحكم الرئيسية وربط الأحداث
```
